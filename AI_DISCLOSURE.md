# AI disclosure

This project was prepared with AI-assisted tooling used for document
organization, code inspection, draft specification, and implementation
support. The AI systems are not treated as independent mathematical
authority.

The repository's substantive computational evidence is the checked-in source
code, JSON output, SHA256 manifest, and the independent standard-library
verifier. `sol-audit/independent_verify_sol_v10.py` intentionally does not
import the original v10 scan or verifier.

The audit text distinguishes exact arithmetic, finite computation, recorded
identities, known results, and unconfirmed hypotheses. AI-generated wording
does not replace a human mathematical review. At the time of this preparation
snapshot, publication-level independent human review and a comprehensive
prior-art survey have not been established.

No private prompts, credentials, model transcripts, or source PDF copies are
required for reproducing the recorded arithmetic checks.
