# SOL AUDIT V10 — 独立再監査

## 監査判定

**v10の核心は確認された。** Dyachenko arXiv:2511.07465v1 の Theorem 9.21(I) にある「格子由来の `alpha,d'` は Theorem 7.3 の平方自由分解 `delta=alpha d'^2` と整合する」という文は、明示条件を満たすED2解に対して成立しない。

分類は **訂正候補（correction confirmed, publication scope unverified）** とする。これはErdős–Straus予想の新解、反証、解決ではない。指定論文v1のパラメータ定義・全解表示・証明経路に関する技術的訂正候補である。

さらに、v10が主に掲げた P=37 より小さい厳密例 P=17 を独立列挙で確認した。P=17では `g` の自然な読みと構成スケールがともに2なので、`g`の曖昧さだけでは不整合を回避できない。

## 本文からの再導出

### 定義の連鎖

1. §5は `g=gcd(b,c)`、`b=b'g,c=c'g` と定義し、`alpha,d'` を `delta` の平方自由因子・平方因子とする。
2. Lemma 7.2は同じ文で、まず `g:=gcd(b,c)` と置いた後に `g:=alpha d'` と再設定する。証明の代入は実際には `gcd(b,c)=alpha d'` を必要とする。
3. Theorem 7.3は `delta=alpha d'^2` と `g:=alpha d'` による表示を「all solutions」と呼ぶ。
4. §9.6は再び `g:=alpha d'`、`delta:=alpha d'^2` とし、後段で `gcd(b,c)=g` を要求する。
5. Theorem 9.21(I) は `gcd(b,c)=d` と書く一方、未導入の `g` から `g_b,g_c,b',c'` を定義し、`alpha=gcd(g,b'+c')`, `d'=g/alpha` とする。その直後に、これがTheorem 7.3の `delta=alpha d'^2` と整合すると述べる。
6. Theorem 9.21(III) は同じ `g,b',c',alpha,d'` を格子 `L` と対角周期に用いる。

### `g` の読み

- 自然な読み: §5と§9.6に従い `g=gcd(b,c)`。
- 代替読み: Lemma 7.2で再設定された構成スケール `g=alpha_sf d_sf`。
- 判断: 本文はどちらかを一意に指定できていない。ただしP=17とP=37では両者が一致するため、どちらの読みでもTheorem 9.21(I)の整合性文は失敗する。

## 主例 P=37 の完全検算

`(P,delta,b,c,A)=(37,5,5,10,10)` とする。

- 37は素数、`37≡1 (mod 4)`。
- `4bc-b-c=4*5*10-5-10=185=37*5=P delta`。
- `(4b-1)(4c-1)=19*39=741=4*37*5+1`。
- `delta|bc`、`A=bc/delta=10`。
- `A=10 <= bP=185 <= cP=370`。
- `g=gcd(5,10)=5`、`g_b=g_c=5`、`b'=1,c'=2`。
- `gcd(b',c')=gcd(b',g)=gcd(c',g)=1`。
- 平方自由分解: `delta=5=5*1^2`、よって `(alpha_sf,d_sf)=(5,1)`、`alpha_sf d_sf=5=g`。
- 格子定義: `alpha_lat=gcd(5,1+2)=1`、`d_lat=5`。
- したがって `alpha_lat d_lat^2=1*25=25 != delta=5`。
- 分数: `4/37=1/10+1/185+1/370`。整数交差積も両辺 `2,738,000`。

よってP=37は、自然な`g`でも構成スケールでも、Theorem 9.21(I)の表示gcd条件を含む算術条件を満たす厳密な内部整合性反例である。

## より小さい例 P=17

独立直接列挙 `P<=349, b,c<=180` の最小厳密例は `(P,delta,b,c,A)=(17,4,2,10,5)` だった。

- `4bc-b-c=80-12=68=17*4`。
- `g=gcd(2,10)=2`、`b'=1,c'=5`、表示gcd条件はすべて1。
- 平方自由側は `(alpha_sf,d_sf)=(1,2)` で `delta=1*2^2=4`、構成スケールも2。
- 格子側は `(alpha_lat,d_lat)=(gcd(2,6),2/2)=(2,1)` で再構成値2。
- `4/17=1/5+1/34+1/170`。

したがってP=17は `g` の解釈差を完全に消した、P=37より小さい訂正例である。

## 族 P=8t-3

すべての整数 `t>=1` について

`P=8t-3, delta=t, b=t, c=2t, A=2t`

と置けば、

`4bc-b-c=8t^2-3t=t(8t-3)=P delta`

かつ `A delta=bc` なので、Pが対象素数なら正しいED2分解を与える。P>3が素数なら `3` はtを割らず、格子側は `alpha_lat=gcd(t,3)=1,d_lat=t`、再構成値は `t^2` となる。したがって `t>1` で `delta=t` と不一致になる。

区別すべき部分族は次の三つである。

- 全ED2族: 上の恒等式を満たす全t。
- Theorem 9.21(I)表示gcd部分族: `b'=1,c'=2,g=t` なので `gcd(2,t)=1`、すなわちtが奇数。素数Pについて `P≡5 (mod 16)`。
- Section 7平方自由primitive部分族: 加えてtが平方自由で、`g=alpha_sf d_sf=t` が成立する部分族。

`P≡5 (mod 16)` の素数が無限にあることを述べる場合のみDirichletの定理を用いる。有限走査は `P<=2,000,000` で全族37,300件、`t>1`の不一致37,299件、表示gcd部分族18,640件（うち不一致18,639件）を再現した。

## P=29本文例

§7.2の例は `alpha=1,d'=2,g=2,b'=2,c'=4,b=4,c=8,delta=4` とする。分解 `4/29=1/8+1/116+1/232` は正しい。一方、

- 実際の `gcd(b,c)=4` は本文の構成 `g=2` と異なる。
- `gcd(b',c')=gcd(2,4)=2` で、Theorem 7.3のprimitive条件を満たさない。

これは主候補P=17/P=37とは独立した補助欠陥である。
