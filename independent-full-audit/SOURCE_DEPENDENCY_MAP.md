# 中心命題の依存関係

| 経路 | 一次資料の役割 | 独立監査判定 | Theorem 9.21 への影響 |
|---|---|---|---|
| Section 7 → Theorem 9.21(I) | 平方因子パラメータ `(alpha_sf, d_sf)` と格子パラメータの一致 | 一般には不一致 | 「consistent」とする橋渡しが無効 |
| Theorem 9.1 → Theorem 9.2 / Corollary 9.3 | 固定指数アフィン格子の点密度から ED2 解の存在・定数平均時間を導く | 非線形 ED2 等式が格子条件に含まれず、推論不能 | 解の非空性と計算量を与えない |
| Lemma 9.22 → Lemma 9.24 | 対角周期から合同条件付き格子点集合全体を一つの対角軌道と同一視 | Lemma 9.24 に反例 | 後段の箱ヒット証明が使えない |
| Lemma 9.24 → Proposition 9.25 | 各座標の合同類代表を同じ対角シフトで同時に箱へ入れる | Proposition 9.25 に反例 | Corollary 9.26 の存在保証が消える |
| Proposition 9.25 → Corollary 9.26 → Theorem 9.21 | 標準箱に admissible point があると主張 | 前提命題が偽。さらに格子点は ED2 解と同義でない | 無条件存在経路が破断 |
| Section 9.12 / Appendix C | 有限列挙と raw pair の正規化で非空性を補う | 正規化式が誤り。有限終了は出力非空を意味しない | 無条件救済にならない |
| Appendix D | 逆点検査と有限被覆で構成を補う | 点検査は正しい方向だが、全 P の被覆は明示的に条件付き | 無条件救済にならない |

## 論理的な終点

Theorem 9.21 の主張そのものに対する反例は得ていない。しかし、v1 が提示する無条件証明経路は複数箇所で破断している。したがって監査結論は「定理が偽」ではなく「v1 では定理が証明されていない」である。
